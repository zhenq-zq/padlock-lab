# AI-assisted development disclosure

AI coding assistance was used to draft and revise source code, translations, documentation and tests. Human authors remain responsible for reviewing scientific assumptions, sequence integrity, source attribution, validation and the released version. AI is not an author. Automated checks are documented separately and do not substitute for human scientific review.

The running design application does not call an AI model. Designs are generated by local deterministic heuristics and the declared thermodynamic engines. No experimental performance is inferred from AI-generated text or simulated samples.

Suggested manuscript disclosure, for author review: “AI-assisted coding tools were used during development and documentation of Padlock Lab. The authors reviewed the resulting code and text and take responsibility for the released software.” Adapt this to the actual final use and ACS policy: https://researcher-resources.acs.org/publish/aipolicy
