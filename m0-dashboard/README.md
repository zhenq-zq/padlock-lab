# Padlock Lab interface

Current installation, supported workflows, export format and test instructions are maintained in [the project README](../README.md).

Main entry points: `design-en.html` (English), `design.html` (Chinese). Computation requires the local Python API. `index.html` and other historical review pages in the development workspace are research archives; they are not part of the whitelisted reader release.

The original experimental reference has18nt/11nt arms and a62nt backbone. Main recommendations are at most3 matched computational designs. See [METHODS](../docs/METHODS.md) for exact ranking, model settings and limits. Earlier descriptions of5 recommendations, a60nt original backbone or a Tm-only ordering belong to historical versions.
