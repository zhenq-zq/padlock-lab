Padlock Lab

Design matched single-zone padlock probes, RCA primers and full LbaCas12a crRNAs. Recommendations are computational and need experimental validation.

  1. Choose the study target or a reference variant, or enter your WT DNA and alternate base.
  2. Select current modules or joint design. Set ligation and readout conditions separately.
  3. Compare up to three recommendations. Viewing a design does not apply its modules to the next request. Use the explicit Apply button to do that.
  4. Export the matched oligos as FASTA and the complete computational record as JSON. Preserve the frozen source version for replay.

Study reference

The study WT78/Mut79 entry is a 50 nt synthetic target with the allele at fragment position 26, drawn from the original study records. The genomic PIK3CA H1047R entry is a separate 61 nt reference. The original 91 nt experimental padlock and matched primer/crRNA are preserved in the application and exported reference record. New computational candidates are distinct from that experimental reference.

Read the results

Boundary extension must be 0/0 for automatic candidates on both supplied alleles. The experimental reference retains its actual boundary behavior. Exact complementarity of 8 nt or more excludes new candidates; 6–7 nt is flagged for review. These checks do not predict enzyme activity or guarantee zero interference.

DNA and free-RNA models are separate. Folding omits independent Mg effects and bound-RNP kinetics. Mean per-base openness is not whole-site opening probability. A structural drawing is a prediction.

Data and reproducibility

Calculations run through your local Python service. Local browser drafts retain inputs; export JSON to preserve results. The schema2 request, source hashes and model conditions support CLI replay. See the source release README and docs/METHODS.md for install commands, equations and limitations.
